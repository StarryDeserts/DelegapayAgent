## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Demo & regression harnesses

For the full demo runbook — env vars, Base Sepolia + MetaMask setup, which flows
are real on-chain vs simulated, manual verification steps, and the headless
regression harnesses — see [`docs/demo-checklist.md`](docs/demo-checklist.md).

```bash
pnpm dev:harness        # dev server on :3001 (the harnesses target this port)
pnpm test:harness       # run all headless harnesses (zero real chain writes)
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
